# Metadata Investigation

## Purpose

Determine the identity of each ebook.

Metadata identifies the book and provides the information required for searching,
duplicate detection, organization, and enrichment.

---

## Questions Answered

- Does the book have a title?
- Does it have an author?
- Does it have an ISBN?
- Does it contain a publisher?
- Does it contain publication information?
- Does it contain cover artwork?
- Is the metadata complete?
- Is the metadata internally consistent?

## Ownership

Metadata owns the identity of an ebook.

If a future feature concerns identifying a book,
it belongs here.

---

## Out of Scope

Metadata never:

- Repairs metadata.
- Downloads metadata.
- Renames files.
- Talks to Scout.

---

## Notes

Metadata identifies the book.

It does not determine whether the metadata is correct.
